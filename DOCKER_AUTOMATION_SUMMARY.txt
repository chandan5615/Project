## Deployment Options (Choose 1)

### Option 1: Quick Development (30 seconds) ⭐
```bash
git clone <repo> && cd sentinel-agent
docker-compose --profile with-ollama up -d
curl http://localhost:8000/api/health
```
- Everything in Docker
- Auto-downloads model
- Perfect for learning

### Option 2: Production with Host Ollama (2 minutes)
```bash
ollama pull llama3:8b && ollama serve
docker-compose up -d
curl http://localhost:8000/api/health
```
- Maximum performance
- Shared Ollama
- Best for production

### Option 3: Enterprise Full Stack
```bash
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```
- SSL/TLS termination
- Nginx reverse proxy
- Monitoring ready
- Backup automation
- For big deployments

## Quick Start (5 Minutes)

### 1. Verify Docker
```bash
./docker-test.sh              # Linux/macOS
docker-test.bat               # Windows
```

### 2. Deploy
```bash
docker-compose --profile with-ollama up -d
```

### 3. Wait for startup (3-5 minutes)
```bash
docker-compose logs -f sentinel-agent
```

### 4. Test
```bash
docker-compose ps                           # Check status
curl http://localhost:8000/api/health       # Test API
open http://localhost:8501                  # View dashboard
```

**That's it! You're running.** 🚀

## Common Commands

```bash
# Start
docker-compose up -d                          # Start services

# Monitor
docker-compose ps                             # View status
docker-compose logs -f sentinel-agent         # Follow logs
docker stats                                  # Resource usage

# Access
docker-compose exec sentinel-agent bash       # Shell access
curl http://localhost:8000/api/health         # API health

# Manage
docker-compose restart sentinel-agent         # Restart
docker-compose down                           # Stop
docker-compose down -v                        # Stop + delete data

# Advanced
docker-compose build --no-cache               # Rebuild
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d  # Production

# Full reference
see docs_markdown/DOCKER_CHEATSHEET.md
```
